A fun core loop needs **challenge**. Add enemies, obstacles, or a timer — and make it ramp up so it gets harder the longer you play (faster spawns, more enemies). Keep it fair: hard enough to be exciting, not so hard players quit.

```quiz
type: mcq
prompt: A good way to keep an arcade game exciting over time is to...
options: [Keep everything exactly the same, Gradually increase the difficulty, Make it impossible immediately]
answer: 1
feedback:
  - "It gets boring if nothing changes."
  - "Right — a rising difficulty curve keeps it tense and fun."
  - "Players quit if it's unfair from the start."
```
