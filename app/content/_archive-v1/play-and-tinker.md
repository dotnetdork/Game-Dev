Programmers learn by *changing things and seeing what happens*. Try it: drag the slider, then press **Run** and watch the number change.

```run
// @slider: speed 50 400 10 200
console.log("The player moves at " + speed + " pixels per second.");
```

Now a tiny goal. Edit the code so it prints the number **10**, then Run:

```run
// @goal: Make it print the number 10
// @expect: 10
let a = 3;
let b = 4;
console.log(a + b);
```
