A **game engine** is a big toolbox of code other people already wrote: drawing pictures to the screen, playing sounds, detecting collisions, running the game every frame. Without one, you'd rebuild all that from scratch for every game.

We use **Phaser**, a game engine for the web written in JavaScript. It handles the plumbing; you focus on *your* game.
