A programming **language** is how you tell a computer what to do. Engines pick a language that fits their goals:

- **Unity** → C#
- **Unreal** → C++ (plus visual "Blueprints")
- **Godot** → GDScript (and C#)
- **Roblox** → Luau (a version of Lua)
- **The web / Phaser** → JavaScript
