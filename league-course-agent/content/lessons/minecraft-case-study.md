Minecraft is a great example of how the language shapes a game. There are actually **two** Minecrafts:

- **Java Edition** (the original, on PC) is written in **Java**. Because it's Java, it's easy to mod — a huge modding community grew around it.
- **Bedrock Edition** (phones, consoles, Windows) is rewritten in **C++**, which runs fast on lots of different devices, so cross-play works.

Same game, different languages, different strengths.
