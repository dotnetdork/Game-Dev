Different engines suit different games:

- **Unity** — hugely popular for 2D and 3D; lots of mobile and indie games.
- **Unreal** — powers many big-budget 3D games; gorgeous graphics.
- **Godot** — free and open-source, great for 2D and small teams.
- **Roblox Studio** — make games *inside* Roblox for its players.
- **Scratch** — blocks you snap together; a friendly first step.
- **Phaser** — 2D games that run in a web browser (what we use).
