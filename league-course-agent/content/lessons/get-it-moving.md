**Challenge.** Get the player moving with the arrow keys.

The AI is in **guided** mode for this lesson: it will make the change, but only if you tell it *exactly* what you want. Vague requests like "make it good" won't work — try something precise like *"when I press the right arrow, set the player's x velocity to 300."*

```quiz
type: mcq
prompt: Which instruction to the AI is specific enough to be useful?
options:
  - Make the player move somehow
  - Make it fun
  - When the left arrow is down, set the player's x velocity to -300
answer: 2
```
