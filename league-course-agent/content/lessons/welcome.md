Welcome! Over this course you'll build a **real game** you can play in your browser and share with your family — and you'll actually understand how it works.

## How the course works

- **Play first.** You'll play games, then learn to change them.
- **Read the code.** You decide what should happen; the AI helps you write it.
- **Finish proud.** By the end you'll have one game that's yours.

## Try some code

This is a runnable snippet. Press **Run** and watch the output:

```run
console.log("Hello, game maker!");
for (let i = 1; i <= 3; i++) {
  console.log("Level " + i + " unlocked");
}
```

> Tip: reading code you didn't write is a real skill — you can ask the tutor about any line, anytime.
